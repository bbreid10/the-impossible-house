# The Impossible House V12: The House of Evidence

## What is different

Chapter 1 now plays as a small cooperative escape room rather than a list of mechanical commands. Every mandatory step corresponds to a real clue or object:

1. In Room A (Study), **read the caretaker's letter**. It shows symbols in three groups, ordered Moons → Stars → Suns.
2. In Room F (East Mirror), **open the brass cabinet**. Count each symbol group to obtain the three-digit code. The cabinet contains the winding key and the **ARE DOORS** fragment.
3. **Use the winding key in the crank** to power the Turning Hall. Rotate B sideways, enter from A.
4. In Room B, **inspect the brass wheel** to uncover the hidden inscription **MIRRORS**.
5. Combine **MIRRORS + ARE DOORS**. Press **Rewrite the House**. A previously impossible pathway now directly connects the distant mirror rooms D and F. This is a real server-validated movement link, not cosmetic copy.
6. Walk through the new mirror pathway and stand different explorers on the Moon and Sun seals in D and E. This opens Room C. Move all explorers into C.

The letter, cabinet state, rule fragments, opened mirror passage, and exit all synchronize in real time across multiplayer browsers. One person cannot remotely read or open a prop located in another room.

## Other changes

- Replaced the indistinct, dark home illustration with a new handmade cutaway using the same high-resolution interior artwork as the actual game.
- Improved visual indications for readable objects, cabinet, rule fragments, active passages, and clue progression.
- Added a real cabinet puzzle UI with numeric input and feedback after incorrect attempts.
- Simplified the first rule change into one action after both fragments are discovered. The other five chapters retain their existing puzzles and mechanics.
- Preserved the public Render Free service and website URL, multiplayer/private/public lobbies, all six chapters, player customization, and shared optional word hunts.

## Public playtest guide

Start **Begin the Story**, read the letter in the first room, then follow the clues. Playtest with two browsers, one on each device; compare what each player sees, and try the same cabinet combination from a different room. Verify rule passage only opens after rewriting, and that both explorers are needed to unlock the exit. Report any point where you did not know what to click without using Help.

## Known limitations

- Room artwork is 2.5D, not a fully navigable 3D environment.
- Online rooms and state live in server memory. They reset when the Free Render instance sleeps, restarts, or redeploys.
- Current game is a playtest prototype, not yet production-grade moderation or long-term saved multiplayer progression.
